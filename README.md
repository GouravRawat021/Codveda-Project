# Codveda-Project
All the tasks I completed during the internship at Codveda 

📂 Project Structure & Tasks
Each task builds on top of the previous one, moving from basic HTML/CSS to advanced interactions and design systems:

Task 1: Responsive Landing Page (/task-1)

* What it is: A clean, mobile-first marketing/landing page.

* Tech Used: Semantic HTML5, CSS Flexbox, and Media Queries.

* Features: Fully responsive navigation, hero section, features grid, and footer with smooth scrolling.

  

Task 2: Interactive Form (/task-2)

* What it is: A user input form with real-time feedback.

* Tech Used: Vanilla JavaScript (DOM manipulation, event listeners).

* Features: Dynamic error messages on blur events, email/password validation, and a success state without page reloads.



Task 3: REST API Integration (/task-3)

* What it is: A dynamic data-fetching interface.

* Tech Used: Native fetch() API with async/await, custom debounce logic.

* Features: Pulls data from a public API, features a real-time search filter, and handles loading/error states gracefully.



Task 4: Tailwind CSS Framework (/task-4)

* What it is: A design system-focused redesign of the landing page.

* Tech Used: Tailwind CSS (via Play CDN).

* Features: Custom color palette, consistent spacing tokens, and utility-first responsive classes (md:, lg:).



Task 5: Advanced Animations (/task-5)

* What it is: Polished UI motion and scroll effects.

* Tech Used: GSAP (GreenSock Animation Platform) & ScrollTrigger.

* Features: Hardware-accelerated transitions (transform and opacity), scroll-based section reveals, and smooth hover states.



Task 6: Django Auth & Component Library (/task-6)

* What it is: A full-stack backend application with a modular frontend architecture.

* Tech Used: Python, Django (User Authentication), HTML/Tailwind, and Storybook configuration.

* Features: Secure user login, registration, and password reset flows, reusable component structuring, and ARIA-compliant accessibility standards for UI elements.
